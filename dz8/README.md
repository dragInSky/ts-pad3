# ДЗ 8

React + TypeScript. Учебный фронт без сервера, данные в localStorage.

```bash
npm install
npm run dev
```

Код подтверждения почты и телефона — `123456`. Пароль — от 6 символов.

Проверка:

1. Зарегистрироваться: имя, почта, телефон и пароль.
2. Выбрать почту или телефон и подтвердить кодом. Откроется профиль.
3. Выйти и войти по почте или телефону с паролем.
4. В «Общих данных» изменить имя или контакты. Новый контакт требует подтверждения.
5. В «Безопасности» подтвердить второй контакт или изменить пароль. Затем войти с новым паролем.

Сборка: `npm run build`.
