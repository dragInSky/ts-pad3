# ДЗ 9

Бэкенд для фронта из ДЗ 8: Express + TypeScript, PostgreSQL. Фронт — React + TypeScript.

Запуск из папки `dz8`:

```bash
docker compose up --build
```

Открыть [localhost:3000](http://localhost:3000). Код подтверждения — `123456`, пароль — от 6 до 128 символов.
Данные и сессии хранятся в PostgreSQL, пароли — в виде хешей scrypt.
Вход сохраняется в HttpOnly cookie на 7 дней. При смене пароля старые сессии перестают работать.

Проверка:

1. Зарегистрироваться: имя, почта, телефон и пароль.
2. Выбрать почту или телефон и подтвердить кодом. Откроется профиль.
3. Выйти и войти по почте или телефону с паролем.
4. В «Общих данных» изменить имя или контакты. Новый контакт требует подтверждения.
5. В «Безопасности» подтвердить второй контакт или изменить пароль. Старый пароль больше не должен подходить.

API:

| Метод | Адрес | Что делает |
| --- | --- | --- |
| POST | `/api/register` | Регистрация |
| POST | `/api/confirm` | Подтверждение контакта |
| POST | `/api/login` | Вход |
| POST | `/api/logout` | Выход |
| GET | `/api/me` | Текущий пользователь |
| PATCH | `/api/profile` | Изменение данных |
| PATCH | `/api/password` | Смена пароля |

Проверка API после запуска:

```bash
docker compose exec app npm test
```

Тест проверяет весь сценарий, ошибки ввода, хеши паролей и отзыв сессий. Свои записи удаляет.
Схема БД — `server/schema.sql`. Подключение: `localhost:5432`, база, логин и пароль — `dz8`.
Остановить: `docker compose down`.
